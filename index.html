Connect your Google Business Profile
This tool reads your real reviews from Google and posts replies directly. You need a free Google Cloud OAuth key first — do this once.
1
Create a Google Cloud project
Go to console.cloud.google.com → click New Project → name it WonderStreaks → click Create.
2
Enable Business Profile API
In your project → APIs & Services → Library → search Business Profile API → click Enable. Also enable My Business Account Management API.
3
Create OAuth credentials
Go to APIs & Services → Credentials → Create Credentials → OAuth client ID → choose Web application → under "Authorised JavaScript origins" add the URL of this page → click Create → copy the Client ID.
4
Paste your Client ID below
Your Client ID looks like: 123456789-abc...apps.googleusercontent.com
Please enter a valid Client ID (ends with .apps.googleusercontent.com)
🔒 Your data stays private. The Client ID only connects this page to your Google account. No data is sent to any third party — replies are posted directly from your browser to Google.
