One-time setup · 5 minutes
Connect your Google Business Profile
This tool reads your real Google reviews and posts replies directly. You need a free Google Cloud OAuth key — set it up once below.
1
Host this file on HTTPS ⚠️ Required
Google Sign-In only works on https:// pages, not from a local file. Host this file on GitHub Pages, Netlify, or any web server.
2
Create a Google Cloud project
Go to console.cloud.google.com → New Project → name it WonderStreaks → Create.
3
Enable the APIs
APIs & Services → Library → search and Enable both:
My Business Account Management API
Google My Business API
4
Configure OAuth Consent Screen
APIs & Services → OAuth consent screen → User type: External → fill App name & email → Save.
Then go to Test users → Add users → add your email → Save.
5
Create OAuth 2.0 Client ID
APIs & Services → Credentials → Create Credentials → OAuth client ID
Application type: Web application

Under "Authorised JavaScript origins" add your hosted URL exactly:
https://yourusername.github.io

⏱ Wait 5–10 minutes after saving before testing.
6
Paste your Client ID below
After creating, copy the Client ID (ends with .apps.googleusercontent.com)
🔒 Your data stays private. Your Client ID only authorises this page with your Google account. Replies post directly from your browser to Google — no third-party servers involved.
